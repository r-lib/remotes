# remotes: R Package Installation from Remote Repositories, Including 'GitHub'

Download and install R packages stored in 'GitHub', 'GitLab',
'Bitbucket', 'Bioconductor', or plain 'subversion' or 'git'
repositories. This package provides the 'install\_\*' functions in
'devtools'. Indeed most of the code was copied over from 'devtools'.
