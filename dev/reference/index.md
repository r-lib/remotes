# Package index

## Package Installation

Tools for installing packages from a variety of locations.

- [`install_bioc()`](https://remotes.r-lib.org/dev/reference/install_bioc.md)
  : Install a development package from the Bioconductor git repository
- [`install_bitbucket()`](https://remotes.r-lib.org/dev/reference/install_bitbucket.md)
  : Install a package directly from Bitbucket
- [`install_cran()`](https://remotes.r-lib.org/dev/reference/install_cran.md)
  : Attempts to install a package from CRAN.
- [`install_dev()`](https://remotes.r-lib.org/dev/reference/install_dev.md)
  : Install the development version of a package
- [`install_git()`](https://remotes.r-lib.org/dev/reference/install_git.md)
  : Install a package from a git repository
- [`install_github()`](https://remotes.r-lib.org/dev/reference/install_github.md)
  : Attempts to install a package directly from GitHub.
- [`install_gitlab()`](https://remotes.r-lib.org/dev/reference/install_gitlab.md)
  : Install a package from GitLab
- [`install_local()`](https://remotes.r-lib.org/dev/reference/install_local.md)
  : Install a package from a local file
- [`install_svn()`](https://remotes.r-lib.org/dev/reference/install_svn.md)
  : Install a package from a SVN repository
- [`install_url()`](https://remotes.r-lib.org/dev/reference/install_url.md)
  : Install a package from a url
- [`install_version()`](https://remotes.r-lib.org/dev/reference/install_version.md)
  : Install specific version of a package.
- [`download_version()`](https://remotes.r-lib.org/dev/reference/download_version.md)
  : Download a specified version of a CRAN package
- [`update_packages()`](https://remotes.r-lib.org/dev/reference/update_packages.md)
  : Update packages that are missing or out-of-date.
- [`system_requirements()`](https://remotes.r-lib.org/dev/reference/system_requirements.md)
  : Query the system requirements for a package (and its dependencies)

## Dependencies

Tools for working with package dependencies.

- [`install_deps()`](https://remotes.r-lib.org/dev/reference/install_deps.md)
  : Install package dependencies if needed.
- [`package_deps()`](https://remotes.r-lib.org/dev/reference/package_deps.md)
  [`local_package_deps()`](https://remotes.r-lib.org/dev/reference/package_deps.md)
  [`dev_package_deps()`](https://remotes.r-lib.org/dev/reference/package_deps.md)
  [`update(`*`<package_deps>`*`)`](https://remotes.r-lib.org/dev/reference/package_deps.md)
  : Find all dependencies of a CRAN or dev package.

Utilities for interacting with GitHub.

  [`github_release()`](https://remotes.r-lib.org/dev/reference/github_refs.md)

  [`parse_github_repo_spec()`](https://remotes.r-lib.org/dev/reference/parse-git-repo.md)
  [`parse_github_url()`](https://remotes.r-lib.org/dev/reference/parse-git-repo.md)
